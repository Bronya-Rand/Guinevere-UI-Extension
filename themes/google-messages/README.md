# Google Messages — first slice

Select **Google Messages** in Guinevere's theme picker. **Google Messages (Legacy)** remains available separately. Saved selections from before the rename still migrate to Legacy once; the new ID now selects this theme.

This version provides the responsive application shell, collapsible navigation, native settings workspace, real persona switching, a live conversation/status header, and persistent palette/background preferences. It keeps ST's original chat, welcome content, composer, attachment controls, extension anchors, and background/sprite elements in place. Start chat opens the existing character/group panel. Conversation actions currently open ST's existing composer action menu.

Desktop uses a persistent navigation sidebar. Narrow screens use an overlay with a backdrop, Back button, and full-screen settings. Appearance offers Google dark or the current ST palette, plus a translucent surface for existing backgrounds. ST's VN mode keeps its bottom dialogue region; Prome's hide-chat and message visibility remain under Prome's control.

The dedicated recent-conversation sidebar, final message-bubble styling, richer Home presentation, and detailed VN/Prome layout tuning are subsequent slices. This theme does not require the theme installer server plugin.
